# Roadmap

GitHub Projects holds task status. Each milestone lists the intended capabilities and acceptance criteria.

## 0. Static portfolio and preview

- [x] Astro project with a responsive profile and still portrait.
- [x] Standalone interview preview with labelled modalities, local history and an accessible close action.
- [x] Versioned analytics event layer, responsive portrait derivatives and English technical documentation.
- [ ] Owner review of desktop and mobile composition and copy.
- [x] Owner approval for publishing the versioned portrait, professional copy and screenshots (November 18, 2026).

## 1. Professional content

- [x] Editorial schema, local sample drafts, publication gate and tests.
- [ ] Create and approve 30–50 candidate fragments.
- [ ] Verify public facts, professional timeline, links and CV.
- [ ] Configure search metadata, OpenGraph and sitemap after choosing a domain.

Acceptance requires approved facts, usable navigation without AI, and verified links.

## 2. Text conversation

- [x] Session, question, answer, citation, abstention and close contract.
- [ ] Rate-limited BFF and temporary session state.
- [ ] Versioned public ingestion and full-text search; evaluate embeddings if required.
- [ ] Evidence-backed answers and abstention, with validated citations.
- [ ] Connect the preview to the API and test known, unknown, sensitive and adversarial questions.

Acceptance requires grounded responses, privacy boundaries, cost limits and a working static fallback.

## 3. Voice

- [ ] Compare real-time voice with a speech-to-text, language-model and text-to-speech pipeline.
- [ ] Implement permissions, turns, interruption, captions and WebRTC where appropriate.
- [ ] Reuse the evidence-backed agent and keep the textual fallback.
- [ ] Test latency, Spanish and English, accessibility and failure behavior.

## 4. Avatar

- [ ] Gather approved video material and consent.
- [ ] Compare two providers for API, cost, lip sync, latency, agreement and shutdown.
- [ ] Connect the selected audio/video adapter and display a persistent AI-generated-avatar label.

## 5. Administration and deployment

- [ ] Editorial roles, MFA, publishing lifecycle and rollback.
- [ ] Release and verify the Umami adapter in production. See [analytics rollout](ANALYTICS.md) and issue #15 for acceptance criteria.
- [ ] Privacy and accessibility review, deployment automation, staging and production.
